Rekha Learning

A gentle learning app for young children · in development

What it is

Rekha Learning teaches young children to write, read and count — starting with single strokes and building up one small step at a time. Every instruction is spoken aloud, so a child who cannot read yet can still use it on their own from the first minute.

How it works

  • Tracing. A guide dot leads the child along each stroke. Finishing always earns something; there is no failure state anywhere in the app.
  • A map, not a menu. Lessons sit along a path the child walks. Earlier chapters stay reachable forever — nothing is ever locked away once passed.
  • A starting point that fits. A short, game-like check finds the right chapter to begin at, instead of guessing from a birthday.
  • Grown-up settings behind a gate. Reports, daily goals, screen-time limits and language sit behind a simple multiplication question a young child cannot answer.

Features

  • Daily goal and streak — a ring that fills and a run of days. Missing a day never costs anything.
  • Awards cabinet — things the child has earned, which can never be taken away again.
  • Screen-time limits — set by a grown-up, with a gentle “all done for today” rather than a lock-out. A lesson already started always finishes.
  • Practice reminders — a daily note to the parent, never to the child, and only on days they have not already practised.
  • Works offline — the whole curriculum and every spoken line ship inside the app.
  • English and Hindi for the grown-up screens.
  • Multiple children on one account, each with their own progress.
